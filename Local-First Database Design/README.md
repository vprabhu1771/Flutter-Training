👍 Yes. A good demo is a **Flutter local-first Sales/Booking app + Laravel API + MySQL**:

**Flutter → SQLite locally → `is_synced = 0` → internet available → Laravel API → MySQL → mark local row synced**

For a wedding-hall application, this same pattern can later be used for bookings, customer details, advance payments, food packages, etc.

I recommend **SQLite (`sqflite`)** for this demo because the relational structure makes sync status and transactional data easy to understand.

# 3. Sync API

`app/Http/Controllers/Api/BookingSyncController.php`

```php
<?php

namespace App\Http\Controllers\Api;

use App\Http\Controllers\Controller;
use App\Models\Booking;
use Illuminate\Http\Request;
use Illuminate\Support\Facades\DB;

class BookingSyncController extends Controller
{
    public function sync(Request $request)
    {
        $request->validate([
            'bookings' => 'required|array',
        ]);

        $synced = [];

        DB::transaction(function () use ($request, &$synced) {

            foreach ($request->bookings as $booking) {

                $validated = validator($booking, [
                    'local_id' => 'required|uuid',
                    'customer_name' => 'required|string',
                    'hall_name' => 'required|string',
                    'booking_date' => 'required|date',
                    'advance' => 'required|numeric',
                ])->validate();

                $record = Booking::updateOrCreate(
                    [
                        'local_id' => $validated['local_id'],
                    ],
                    [
                        'customer_name' => $validated['customer_name'],
                        'hall_name' => $validated['hall_name'],
                        'booking_date' => $validated['booking_date'],
                        'advance' => $validated['advance'],
                    ]
                );

                $synced[] = [
                    'local_id' => $record->local_id,
                    'server_id' => $record->id,
                ];
            }
        });

        return response()->json([
            'success' => true,
            'synced' => $synced,
        ]);
    }
}
```

The important part is:

```php
Booking::updateOrCreate(
    [
        'local_id' => $validated['local_id'],
    ],
    [...]
);
```

This makes the API **idempotent**.

If Flutter sends the same booking twice because the network failed after Laravel received it, Laravel won't create a duplicate.

# 6. SQLite database

Create:

`lib/database/app_database.dart`

```dart
import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';

class AppDatabase {
  static Database? _database;

  static Future<Database> get database async {
    if (_database != null) {
      return _database!;
    }

    _database = await _initDatabase();

    return _database!;
  }

  static Future<Database> _initDatabase() async {
    final dbPath = await getDatabasesPath();

    final path = join(
      dbPath,
      'wedding_hall.db',
    );

    return openDatabase(
      path,
      version: 1,
      onCreate: (db, version) async {
        await db.execute('''
          CREATE TABLE bookings (
            id TEXT PRIMARY KEY,
            customer_name TEXT NOT NULL,
            hall_name TEXT NOT NULL,
            booking_date TEXT NOT NULL,
            advance REAL NOT NULL,
            is_synced INTEGER NOT NULL DEFAULT 0,
            created_at TEXT NOT NULL
          )
        ''');
      },
    );
  }
}
```

# 8. Save booking locally

`lib/services/booking_service.dart`

```dart
import 'package:uuid/uuid.dart';

import '../database/app_database.dart';
import '../models/booking.dart';

class BookingService {
  final _uuid = const Uuid();

  Future<void> createBooking({
    required String customerName,
    required String hallName,
    required String bookingDate,
    required double advance,
  }) async {
    final db = await AppDatabase.database;

    final booking = Booking(
      id: _uuid.v4(),
      customerName: customerName,
      hallName: hallName,
      bookingDate: bookingDate,
      advance: advance,
      isSynced: 0,
      createdAt: DateTime.now().toIso8601String(),
    );

    await db.insert(
      'bookings',
      booking.toMap(),
    );
  }

  Future<List<Booking>> getBookings() async {
    final db = await AppDatabase.database;

    final result = await db.query(
      'bookings',
      orderBy: 'created_at DESC',
    );

    return result
        .map((row) => Booking.fromMap(row))
        .toList();
  }
}
```

Notice something important:

**Saving does not require internet.**

```dart
await db.insert(
  'bookings',
  booking.toMap(),
);
```

The customer can book even when the wedding hall has **zero network**.

# 9. Sync service

Create:

`lib/services/sync_service.dart`

```dart
import 'dart:convert';

import 'package:http/http.dart' as http;

import '../database/app_database.dart';

class SyncService {
  static const String apiUrl =
      'http://10.0.2.2:8000/api';

  Future<void> syncBookings() async {
    final db = await AppDatabase.database;

    final rows = await db.query(
      'bookings',
      where: 'is_synced = ?',
      whereArgs: [0],
    );

    if (rows.isEmpty) {
      return;
    }

    final response = await http.post(
      Uri.parse('$apiUrl/sync/bookings'),
      headers: {
        'Content-Type': 'application/json',
        'Accept': 'application/json',
      },
      body: jsonEncode({
        'bookings': rows.map((row) {
          return {
            'local_id': row['id'],
            'customer_name': row['customer_name'],
            'hall_name': row['hall_name'],
            'booking_date': row['booking_date'],
            'advance': row['advance'],
          };
        }).toList(),
      }),
    );

    if (response.statusCode != 200) {
      throw Exception(
        'Sync failed: ${response.statusCode}',
      );
    }

    final data = jsonDecode(response.body);

    if (data['success'] == true) {
      final synced = data['synced'] as List;

      for (final item in synced) {
        await db.update(
          'bookings',
          {
            'is_synced': 1,
          },
          where: 'id = ?',
          whereArgs: [
            item['local_id'],
          ],
        );
      }
    }
  }
}
```

# 10. Simple Flutter screen

`lib/main.dart`

```dart
import 'package:flutter/material.dart';

import 'services/booking_service.dart';
import 'services/sync_service.dart';

void main() {
  runApp(const WeddingApp());
}

class WeddingApp extends StatelessWidget {
  const WeddingApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      title: 'Wedding Hall',
      theme: ThemeData(
        colorSchemeSeed: Colors.deepPurple,
        useMaterial3: true,
      ),
      home: const BookingScreen(),
    );
  }
}

class BookingScreen extends StatefulWidget {
  const BookingScreen({super.key});

  @override
  State<BookingScreen> createState() =>
      _BookingScreenState();
}

class _BookingScreenState extends State<BookingScreen> {

  final customerController =
      TextEditingController();

  final hallController =
      TextEditingController(
        text: 'Grand Wedding Hall',
      );

  final bookingService = BookingService();
  final syncService = SyncService();

  List bookings = [];

  @override
  void initState() {
    super.initState();
    loadBookings();
  }

  Future<void> loadBookings() async {
    final result =
        await bookingService.getBookings();

    setState(() {
      bookings = result;
    });
  }

  Future<void> saveBooking() async {

    if (customerController.text.isEmpty) {
      return;
    }

    await bookingService.createBooking(
      customerName: customerController.text,
      hallName: hallController.text,
      bookingDate:
          DateTime.now().toIso8601String(),
      advance: 10000,
    );

    customerController.clear();

    await loadBookings();

    if (mounted) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text(
            'Booking saved locally',
          ),
        ),
      );
    }
  }

  Future<void> sync() async {

    try {

      await syncService.syncBookings();

      await loadBookings();

      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text(
              'Sync completed',
            ),
          ),
        );
      }

    } catch (e) {

      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text(
              'Sync failed: $e',
            ),
          ),
        );
      }
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text(
          'Wedding Hall Booking',
        ),
        actions: [
          IconButton(
            icon: const Icon(
              Icons.sync,
            ),
            onPressed: sync,
          ),
        ],
      ),

      body: Padding(
        padding: const EdgeInsets.all(16),

        child: Column(
          children: [

            TextField(
              controller: customerController,
              decoration: const InputDecoration(
                labelText: 'Customer Name',
                border: OutlineInputBorder(),
              ),
            ),

            const SizedBox(height: 12),

            TextField(
              controller: hallController,
              decoration: const InputDecoration(
                labelText: 'Hall Name',
                border: OutlineInputBorder(),
              ),
            ),

            const SizedBox(height: 12),

            SizedBox(
              width: double.infinity,
              child: ElevatedButton(
                onPressed: saveBooking,
                child: const Text(
                  'SAVE BOOKING',
                ),
              ),
            ),

            const SizedBox(height: 20),

            Expanded(
              child: ListView.builder(
                itemCount: bookings.length,
                itemBuilder: (context, index) {

                  final booking =
                      bookings[index];

                  return Card(
                    child: ListTile(
                      title: Text(
                        booking.customerName,
                      ),

                      subtitle: Text(
                        '${booking.hallName}\n'
                        'Advance: ₹${booking.advance}',
                      ),

                      trailing: booking.isSynced == 1
                          ? const Icon(
                              Icons.cloud_done,
                              color: Colors.green,
                            )
                          : const Icon(
                              Icons.cloud_off,
                              color: Colors.orange,
                            ),
                    ),
                  );
                },
              ),
            ),
          ],
        ),
      ),
    );
  }
}
```

Now you have a working local-first flow.

# 12. Add automatic background synchronization

Once the basic demo works, add `Workmanager`.

Create:

`lib/background_sync.dart`

```dart
import 'package:workmanager/workmanager.dart';

import 'services/sync_service.dart';

const syncTask = 'syncWeddingBookings';

@pragma('vm:entry-point')
void callbackDispatcher() {

  Workmanager().executeTask(
    (task, inputData) async {

      try {

        final syncService = SyncService();

        await syncService.syncBookings();

        return true;

      } catch (e) {

        return false;
      }
    },
  );
}
```

Initialize in `main.dart`:

```dart
void main() async {

  WidgetsFlutterBinding.ensureInitialized();

  await Workmanager().initialize(
    callbackDispatcher,
  );

  await Workmanager().registerPeriodicTask(
    'wedding-sync-task',
    syncTask,
    frequency: const Duration(
      minutes: 15,
    ),
    constraints: Constraints(
      networkType: NetworkType.connected,
    ),
  );

  runApp(const WeddingApp());
}
```

### One important production improvement

For a real wedding-hall application, I would **not** stop at a single `is_synced` field. Use a sync queue:

```text
sync_queue
------------------------------------------------
id
entity_type
entity_id
operation       CREATE / UPDATE / DELETE
payload
status          PENDING / SYNCED / FAILED
attempt_count
last_error
created_at
updated_at
```

That lets you safely support:

* Offline booking creation
* Offline booking edits
* Offline cancellation
* Offline advance-payment entries
* Retry after failed requests
* Duplicate prevention
* Conflict handling
* Multiple devices
* Audit history

For your wedding-hall use case, this is the architecture I'd build toward:

```text
Flutter
│
├── UI
├── Repository
├── SQLite
│   ├── bookings
│   ├── customers
│   ├── payments
│   └── sync_queue
│
├── Connectivity Monitor
│
└── Background Sync
        │
        ▼
Laravel REST API
│
├── Authentication
├── Booking API
├── Customer API
├── Payment API
└── Sync API
        │
        ▼
MySQL / PostgreSQL
```

This gives you **instant local operation at the hall**, while Laravel/MySQL remains the central source for reports, admin, multiple devices, and backups.
